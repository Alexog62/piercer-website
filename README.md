# PIERCER website starter

This is a responsive, static one-page website for the PIERCER trading education brand.

## Files
- `index.html` — page content and sections
- `style.css` — design and responsive styling
- `script.js` — mobile navigation and current year

## Preview locally
Open `index.html` in a web browser.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new **public** repository, for example `piercer-website`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. GitHub will provide a free `https://YOUR-USERNAME.github.io/piercer-website/` address.

## Before launch
- Replace the abstract initial-based hero visual with your preferred AI portrait or brand image if desired.
- Replace the temporary email link with your real business email, WhatsApp, Telegram, or booking link.
- Add actual course details, mentorship prices, terms, privacy policy, and refund policy before accepting payments.
- The chart graphics and text are illustrative. No performance claims or testimonials are included.
- Google Fonts load from the internet; if offline, system fonts will be used.
- A custom domain such as `IamPiercer.com` is optional and normally costs money to register.
